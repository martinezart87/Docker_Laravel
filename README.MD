## Konfiguracja GIT - SSH

Generowanie klucza ssh dla githuba:

```
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
```

Dodanie klucza do GitHuba:

1. Zaloguj się do swojego konta GitHub.
2. Przejdź do ustawień konta.
3. Wybierz „SSH and GPG keys”.
4. Wybierz „New SSH key”.
5. Wklej skopiowany klucz i nadaj mu tytuł, np. "My SSH Key".
6. Kliknij „Add SSH key”.
